\# EventSphere – Event Management Website



A modern, fully responsive event management website built with \*\*HTML5, CSS3, and vanilla JavaScript\*\*.



\## ✨ Features

\- Attractive hero section with gradient heading

\- Search bar for filtering events by name/venue/description

\- Category filters (Conference, Workshop, Music, Sports, Art)

\- Event cards with images, dates, venues, and descriptions

\- Registration modal with JavaScript-based form validation

\- Success confirmation message after registration

\- \*\*Dark/Light mode toggle\*\* (persisted with localStorage)

\- \*\*LocalStorage-based registration tracking\*\* — buttons show "Registered ✓" after signup

\- Fully responsive design (mobile, tablet, desktop)

\- Smooth hover animations and transitions



\## 🛠️ Tech Stack

| Layer | Tech |

|-------|------|

| Markup | HTML5 |

| Styling | CSS3 (Grid, Flexbox, CSS Variables) |

| Logic | Vanilla JavaScript (ES6) |

| Icons | Font Awesome 6 |
